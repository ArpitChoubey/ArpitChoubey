### 🧑‍💼 How I Lead Quality

- **Test strategy & architecture:** I define the test pyramid, decide what to automate and what to leave out, and design frameworks so teams can keep extending them
- **Quality gates in CI/CD:** I run tests on every PR, shard them in parallel, quarantine flaky tests, and publish trace and report artifacts
- **Full-stack coverage:** I balance UI, API, database and accessibility (WCAG 2.1/2.2 AA, axe-core) checks to catch defects before production
- **Team leadership:** For 1+ year I've led teams of 3–4 members on mobile programming and freelance projects, owning delivery, task planning, code reviews and mentoring
- **Raising the team's bar:** I set framework conventions, review automation PRs, and coach developers and QA engineers to write reliable tests
- **Responsible AI adoption:** I use AI to speed up test authoring without weakening the assertions
